# Move Together MVP

## Purpose
두 사람이 서로의 오늘 운동 여부를 보고, 찌르거나 반응하면서 서로 운동하게 만든다.

## Primary user
연인(또는 친한 2인)이 매일 앱을 열어 "나 했나 / 상대 했나 / 둘 다 했나"를 확인하는 상황.

## Core flow (one)
앱 실행 → 오늘 탭에서 상대 상태 확인 → "아직 운동 전"이면 찌르기 → (상대 운동, 알림) → 상대 카드에 리액션 → "오늘 둘 다 성공"

## Screens in scope
- 오늘 (상태 3종): 상대 운동 전 / 상대 운동 완료(리액션) / 둘 다 완료
- 운동 완료 Step 1: 운동 종류(복수 선택)
- 운동 완료 Step 2: 오늘의 순간(사진/영상, 선택)
- 운동 완료 결과(작은 보상)
- 찌르기 완료 피드백
- 둘 다 성공 보상 화면
- 기록: 날짜별 둘의 운동 앨범
- 연결하기: 초대 링크 / 코드 입력

## Out of scope for now
Splash, 로그인/가입, 닉네임 설정(기존 화면 유지), 설정 상세, 댓글, 통계/칼로리/거리.

## Style notes
흰색/밝은 배경, 큰 카드·큰 버튼, 둥근 모서리, 큰 체크 표시, 이모지 제한적 사용, 사진/영상은 크게,
애니메이션은 완료 순간에만. → 레이아웃 잠금 후 스타일 단계에서 처리.

## Assumptions
- 하단 탭 2개(오늘/기록). 알림·설정은 오늘 탭 상단 아이콘 버튼.
- 카드 하나 = 사람 한 명. 나 카드가 위, 상대 카드가 아래.
- 미디어는 선택사항. [건너뛰기]로 사진 없이 완료 가능. 최대 3개, 영상 10초.
- 찌르기는 하루 1회, 메시지 직접 작성 없음. 누르면 버튼이 "오늘 찔렀어요"로 바뀜.
- 리액션은 상대 완료 카드 안에 4개(❤️💪🔥👏) 버튼으로 바로 노출.
- 둘 다 완료되면 한 번 전체화면 보상 → 닫으면 오늘 탭은 "둘 다 성공" 배너 상태.
- 연결 전(상대 없음)이면 오늘 탭 대신 연결하기 화면.
- 기록 탭은 백엔드 목록 API가 새로 필요.

## Open questions
1. 상대 이름: 상대 닉네임 그대로? 아니면 "여자친구" 같은 관계명 지정?
2. 둘 다 성공 보상: 전체화면 1회 + 오늘 탭 배너(가정) vs 오늘 탭 안에서만 표시?
3. 기록 탭: 둘 다 한 날만 강조하고 "나만/상대만" 날은 흐리게(가정) 괜찮은지?
